# Knowledge library (samples go here)

Every file in this directory is copied next to the agent's working tree as
`automation-knowledge/` (kept out of change detection), so implementers and
reviewers can consult it while they work.

Put project knowledge here that a ticket cannot carry on its own: past
incident write-ups, architectural decisions, naming conventions, review
checklists. One topic per file, plain Markdown, any file name.

The engine ships none: knowledge belongs to the instance repository, not to
the framework.
